## What is GeoJSON?

GeoJSON is an open standard format for encoding and exchanging geospatial data, built on JavaScript Object Notation (JSON). It is widely used in Geographic Information Systems (GIS) and web mapping due to its simplicity, human-readability, and compatibility with web technologies. GeoJSON represents geographic features such as points, lines, polygons, and their multi-part counterparts (e.g., MultiPolygon). Each feature consists of a geometry object (spatial data) and properties (non-spatial metadata), making it ideal for storing both location and descriptive information. GeoJSON uses the WGS 84 coordinate system, with coordinates expressed in decimal degrees.
